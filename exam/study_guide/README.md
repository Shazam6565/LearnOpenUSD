# NCP-OUSD Study Guide — Topic Breakdown

Per-domain breakdowns extracted from the official **NVIDIA-Certified Professional: OpenUSD
Development Exam Study Guide**, v1.1.0 (OCT25). Each file contains that domain's description,
its numbered exam objectives, and the full "NVIDIA Courses and Suggested Readings" list with the
clickable links recovered from the PDF.

- **Source PDF:** `ncp-open-usd-development-study-guide (1).pdf` (repo root)
- **Links:** extracted from the PDF's link annotations (PyMuPDF), mapped to their anchor text.
  URLs are reproduced exactly as published in the document.

## Notes on source fidelity

- **LIVRPS / LIVERPS:** the guide spells the strength-ordering mnemonic both ways — "LIVRPS" in the
  Composition description and "LIVERPS" in objective 1.6 / the glossary. Both denote the same
  concept. See [01-composition.md](01-composition.md).
- **Duplicate link in Customizing USD:** the "USD FAQ - Isn't USD Just Another File Format?" entry
  links to the same ACM DOI as "USD in Production" — an apparent copy-paste in NVIDIA's PDF.
  Reproduced as published; see [03-customizing-usd.md](03-customizing-usd.md).
